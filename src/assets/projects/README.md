# Екранни снимки на проектите

Един файл на проект, кръстен на домейна без разширението:

| Проект | Файл |
| --- | --- |
| routinly.org | `routinly.png` |
| bulgariaradio.com | `bulgariaradio.png` |
| plumeo.ink | `plumeo.png` |
| ponomer.com | `ponomer.png` |
| communitylovable.bg | `communitylovable.png` |
| pensionen-kalkulator.bg | `pensionen-kalkulator.png` |

Приемат се `.png`, `.jpg`, `.jpeg`, `.webp` и `.avif`. Картата взима файла
автоматично по това име — няма нужда да се пипа код. Ако файлът липсва, картата
се показва с инициал вместо снимка, така че нов проект може да се добави и без
снимка.

Картата изрязва снимката в съотношение 16:10 и я подравнява отгоре, за да остане
видима горната част на сайта. Затова снимката трябва да е от началото на
страницата — долният край така или иначе се отрязва.

Astro ги смалява и преобразува в WebP при билд, така че големината на файла не е
проблем. Алтернативният текст (`alt`) за всяка снимка се задава в
`src/data/projects.ts`, до останалите данни за проекта.

Нови снимки най-лесно се правят с `npm run shots` (виж
`scripts/capture-screenshots.mjs`).
