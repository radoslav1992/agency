# Корици на наръчниците

Името на файла е `cover` от `src/data/guides.ts` плюс разширение:

    ai-receptionist  →  src/assets/guides/ai-receptionist.webp

Приемат се `.webp`, `.png`, `.jpg`, `.avif` — без значение кой. Astro сама
превръща корицата в `webp` в четири размера при build; PNG остава изходник и
не се тегли от посетители. Страницата намира файла с глоб, затова липсващ
файл НЕ чупи build-а, а показва рамка на мястото на корицата.

Страницата се предрендерира, значи преобразуването става при build. Това е
разликата с `/booking/`, която се смята при заявка и заради която там
изображенията минаваха през счупения маршрут `/_image`.

Съотношението на корицата е около 2:3 (книжен формат). Дългата страна от
1400 пиксела стига: Astro сама прави по-малките размери.
