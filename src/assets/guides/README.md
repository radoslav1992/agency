# Корици на наръчниците

Името на файла е `cover` от `src/data/guides.ts` плюс разширение:

    ai-receptionist  →  src/assets/guides/ai-receptionist.webp

Приемат се `.webp`, `.png`, `.jpg`, `.avif`. Страницата ги намира с глоб —
затова липсващ файл НЕ чупи build-а, а показва рамка на мястото на корицата.

Съотношението на корицата е около 2:3 (книжен формат). Дългата страна от
1400 пиксела стига: Astro сама прави по-малките размери.
